Gizlilik Politikası Bağlantısı (URL) Nereye Eklenecek?
1.Google Play Console hesabınıza giriş yapın ➔ WorkLogix uygulamasını seçin.
2.Sol menüden Uygulama İçeriği (App Content) sekmesine girin.
3.Gizlilik Politikası (Privacy Policy) başlığı altındaki Başlat / Düzenle butonuna tıklayın.
4.Oluşturduğunuz Gizlilik Politikası URL adresini yapıştırıp Kaydet butonuna basın.
