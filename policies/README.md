## Gizlilik Politikası Bağlantısı (URL) Nereye Eklenecek?
* Google Play Console hesabınıza giriş yapın ➔ WorkLogix uygulamasını seçin.
* Sol menüden Uygulama İçeriği (App Content) sekmesine girin.
* Gizlilik Politikası (Privacy Policy) başlığı altındaki Başlat / Düzenle butonuna tıklayın.
* Oluşturduğunuz Gizlilik Politikası URL adresini yapıştırıp Kaydet butonuna basın.
